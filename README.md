# 🎵 Rakha's Interactive Portfolio

Selamat datang di situs web portofolio pribadi saya! Alih-alih menggunakan tata letak portofolio grid konvensional, saya merancang situs ini dengan tema **Pemutar Musik Interaktif**. 

Setiap "Album" atau "Lagu" di dalam pemutar ini merepresentasikan perjalanan akademik, *coursework*, riset kelompok, hingga proyek pengembangan *Software Engineering* dan *Machine Learning* yang pernah saya kerjakan.

## 🎧 Konsep & Interaksi UI

Portofolio ini tidak hanya menampilkan daftar proyek, tetapi juga menonjolkan kemampuan manipulasi DOM dan CSS tingkat lanjut:
- **Immersive Zoom Experience:** Saat pengguna memutar "lagu" (membuka detail proyek), *cover* album akan membesar ke ukuran penuh (*fullscreen*) dengan transisi `cubic-bezier` yang sangat mulus tanpa *jank*.
- **Dynamic Neon Vibe:** Mode *fullscreen* memicu latar belakang gradasi neon animasi (`::after` + `opacity`) yang dirancang untuk menimpa gaya halaman bawaan secara universal, memberikan kesan modern dan *cyber*.
- **Responsive Contrast:** Warna teks otomatis beradaptasi saat elemen membesar, memastikan deskripsi proyek selalu terbaca dengan jelas di atas latar belakang yang gelap atau terang.

## 💽 "Tracklist" Pilihan (Featured Projects)

Berikut adalah beberapa karya utama yang bisa kamu "dengarkan" di dalam portofolio ini:
1. **SorTrash:** Sistem klasifikasi sampah berbasis AI menggunakan arsitektur YOLOv8, di-*deploy* terintegrasi melalui Hugging Face Spaces dan Vercel.
2. **InVidious:** *Game* horor *multiplayer* 3D yang dibangun menggunakan Unity 6, Netcode for GameObjects, dan sinkronisasi jaringan.
3. **E-Zoo & salLantis:** Eksplorasi pengembangan aplikasi dari *mobile* (Flutter) hingga *desktop* platform (Tauri, Rust, Next.js).
4. **Machine Learning & Data Mining:** Berbagai eksperimen pengolahan data, implementasi algoritma (Scikit-learn, PyTorch, OpenCV), hingga sistem rekomendasi.
